## 적용 방법

1. 아래 체크섬과 일치하는 일본어 독립 실행판 FDI를 준비합니다
2. [Madou Monogatari - Michikusa Ibun (PC-98) KR v1.0.0.bps](https://raw.githubusercontent.com/mcpads/madou-monogatari-kr-patch/main/Madou%20Monogatari%20-%20Michikusa%20Ibun%20%28PC-98%29%20KR%20v1.0.0.bps)를 다운로드합니다
3. [Floating IPS (Flips)](https://www.smwcentral.net/?p=section&a=details&id=11474) 등 BPS 적용 프로그램으로 원본 FDI에 패치를 적용합니다
